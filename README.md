# 田 · 档案之野 — The Field Archive

一个以「田」为主题的交互式数据可视化单页网站，灵感来自 The Pudding 风格的数据新闻作品。
画布如一块可以无限缩放、平移的田野：横轴是年代（先秦 → 当代），纵轴是四个档案系列，
208 条档案条目化作田垄间的纸卡，等待被翻阅。

## 本地运行

```bash
cd tian
npm run dev          # 默认 http://127.0.0.1:7100/
npm run dev -- --port 3000 --host 0.0.0.0   # 可透传 host/port
```

无需安装任何依赖（`server.js` 是零依赖静态服务器）。
也可以用任意静态服务器直接托管本目录（如 `npx serve`、VS Code Live Server）。

## 交互一览

| 操作 | 说明 |
|---|---|
| 滚轮 / 双指捏合 | 缩放（以指针为中心） |
| 拖拽 / 方向键 / 右上按钮 | 平移 |
| 点击纸卡 | 进入详情视图（左侧信息栏 + 中央大图/诗文） |
| 点击远处圆点簇 | 飞入该年代×系列的团簇 |
| 左侧搜索框 | 实时过滤条目、地名、标签（命中过少时自动飞过去） |
| 展厅 / 系列 / 枢纽互见 | 胶囊筛选，再点取消 |
| 开启导览 | 六站自动巡航：甲骨文 → 井田制 → 耕织图 → 陶渊明 → 梵高 → 越后妻有 |
| 再看一丘 | 随机跳下一条档案详情 |
| 0 / Esc | 回到全景 / 清除筛选；详情内 Esc 返回田野 |

## 数据

- 来源：四份石墨档案表格（形式灵感 49 / 社会素材 60 / 文学意向 50 / 经典艺术 49 条）
- 抽取：`../shimo/extract_for_web.py`（openpyxl 解析字段 + 内嵌图片，PIL 生成 860px 大图与 260px 缩略图）
- 产出：`data/archives.js`（`window.FIELD_META` + `window.FIELD_DATA`）、`assets/img/*.jpg`
- 分类：按《田主题策展分类方案》八分法（C1 字形之源 … C8 凝视之史），关键词规则自动归类
- 年代：从「年代」字段解析数值年份（含公元前），未注明者按正文/出处推断

## 技术

- 纯前端：原生 HTML + CSS + JavaScript，单 Canvas 2D 渲染，无框架无构建
- 相机：自研 wheel/拖拽/双指缩放 + 缓动补间飞行动画
- LOD：远处聚合圆点簇 → 近处迷你卡 → 放大完整卡（图片懒加载、视口外剔除）
- 响应式：桌面鼠标与移动端触控均可操作，窄屏左侧面板默认收起
